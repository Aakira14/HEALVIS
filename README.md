# 🩺 Healvis

> Your AI-powered health assistant that helps users understand symptoms, medicines, and basic health guidance in a simple and friendly way.

---

## ✨ About the Project

Healvis is a smart health assistant designed to make basic medical information more accessible and easy to understand. It helps users by providing quick guidance on symptoms, general health queries, and medicine-related information in a conversational way.

This project was built as part of a hackathon to explore how AI can improve everyday health awareness and decision-making.

---

## 🚀 Features

* 💬 AI-powered health chat assistant
* 💊 Basic medicine information support
* 🧠 Symptom-based guidance (non-diagnostic)
* ⚡ Fast and simple user experience
* 📱 Clean and responsive UI

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/Aakira14/healvis.git
cd healvis
```

### 2. Install dependencies

```bash
npm install
```

### 3. Setup environment variables

Create a `.env` file:

```env
API_KEY=your_api_key_here
```

### 4. Run the project

```bash
npm start
```
